# Support

- Read the [user manual](https://dawndust.github.io/workflow-monitor/) and [troubleshooting guide](https://dawndust.github.io/workflow-monitor/troubleshooting/) first.
- Ask usage and workflow questions in [GitHub Discussions](https://github.com/DawnDust/workflow-monitor/discussions).
- Use the Bug Report Issue Form for reproducible defects and the Feature Request form for proposals.
- Use GitHub private vulnerability reporting for security issues.

Before sharing a diagnostic bundle, open it and remove anything you do not want to publish. The project does not automatically upload diagnostics, telemetry, repository content, or credentials.

Support is community-based and has no guaranteed response time. Please include the Workflow Monitor version, Windows version, concise reproduction steps, expected behavior, and actual behavior.
