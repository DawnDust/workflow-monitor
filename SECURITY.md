# Security policy

## Supported versions

Only the latest published minor release receives security updates. Users should upgrade before reporting an issue that only affects an older release.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** action in the repository Security tab. Do not open a public Issue for suspected vulnerabilities.

Include the affected version, operating system, impact, reproduction steps, and any suggested mitigation. Remove project data, credentials, tokens, personal information, and confidential research material from screenshots or attachments.

The maintainers will acknowledge a report when it is received, assess severity, coordinate a fix and disclosure timeline, and credit the reporter unless anonymity is requested. No bounty program is currently offered.

Workflow Monitor does not automatically upload diagnostic data. A diagnostic ZIP must be reviewed and attached manually.
