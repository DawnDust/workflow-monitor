# 使用仪表盘

仪表盘用于观察和导航。生命周期写入由 AI 或高级 CLI 通过结构化服务完成。

## 主要页面

- **工作流：**活动与历史任务、动作可用性、研究篇章和科研探索。
- **概览：**项目说明、当前研究篇章、判断、断点、阻塞、下一步、代码交付和资料摘要。
- **搜索：**检索任务、探索和登记资料，不翻译其中内容。
- **资料：**导航标准资料目录，并在展开后按需读取登记条目。
- **研究篇章：**按篇章组织目标、完成工作、相关探索和资料。
- **设置：**语言、状态解释、高级交付和诊断视图，以及产品信息。

## 设置

“语言”只改变本机系统文字。“解释”说明已知工作流和 Git 状态。“高级查看”保留版本状态、动作可用性、诊断和原始事件；成本较高的内容仅在展开时加载。“关于”注明作者 DawnDust，并提供官方仓库、用户手册、版本、构建提交、MIT License、问题反馈和私密漏洞报告入口。

外部链接只有在用户明确点击后才会打开；项目内容和诊断数据不会自动上传。

![Workflow Monitor 设置页](../assets/workflow-monitor-settings.png)

主题和刷新按钮继续位于顶部，不属于设置配置。

## 资料和灵感

项目资料放在标准 `resources/` 目录并登记到索引。`resources/sparks/` 是低约束的 Markdown 灵感池：未登记灵感可以自由保存，需要检索时可选择性登记。

## 研究注意事项

概览页最多显示三条由现有结构化事实确定性推导的研究注意事项，例如已登记资料缺失、显式矛盾证据、篇章阻塞或活动探索缺少步骤。它们同时进入 AI 读取的 Context，带有来源并可跳转到现有只读页面，但不是科学结论，也不会自动执行修复。未登记 Sparks 保持自由，不做历史存在性追踪。

## 诊断

内部故障可能生成本地轮转、脱敏的诊断记录。导出只会在本机生成 ZIP。附加到 Issue 前必须逐项检查；程序不会自动上传任何内容。
